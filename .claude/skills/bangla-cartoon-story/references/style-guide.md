# স্টাইল-গাইড

## ১. ফ্রেম-লেআউট (১০৮০×১৯২০)
- **দৃশ্য-শিরোনাম চিপ** (`TitleChip`): ওপরে মাঝখানে (top 100), ক্রিম পিল + ৪px লাল বর্ডার + লাল ডট, ৪২px। প্রতি দৃশ্যে পপ-ইন। শিরোনাম ২–৩ শব্দে দৃশ্যের সারকথা ("অভিযোগ", "চুপচাপ কেন?", "বুকে জড়িয়ে")।
- **ক্যাপশন কার্ড** (`Captions`): কেন্দ্র y=1500, সর্বোচ্চ প্রস্থ ৮৮০, ক্রিম `#F4EFE8`, রেডিয়াস ২৬, ছায়া। ৫৬px 700, গাঢ় `#2A2420`; কি-ওয়ার্ড উচ্চারণের মুহূর্তে লাল `#C8401F` হয়ে হালকা পপ। **সর্বোচ্চ ২ লাইন।** নিচের ~১৮০px ফাঁকা।
- **সংলাপ:** কার্ডের ওপরে ছোট বক্তা-লেবেল `● নাম` আর লেখা “উদ্ধৃতি”-তে। **কথক:** লেবেল নেই, উদ্ধৃতি নেই।
- **স্ট্যাম্প** (`Stamp`): কাত ক্রিম লেবেল, লাল বর্ডার/লেখা, ঝাঁকুনি দিয়ে বসে — y≈300–330 (চিপের নিচে)। **চিপ** (`Chip`): গোল পিল, রঙিন বর্ডার — ভাবনা/প্রশ্ন/ধারণা ("কোনো কারণ?", "বেশি জরুরি")।
- চরিত্রের পা: দাঁড়ানো `FY=1420`, সোফায় বসা `SY=1600`, ছাদের বেঞ্চে `RY=1625`; স্কেল সাধারণত ১.৩।

## ২. রং ও থিম (হালকা, উজ্জ্বল)
- ঘর (দিন): দেয়াল ক্রিম/পিচ `#FCEBDD` বা পুদিনা `#E2F2EA`, পর্দা পিচ/সবুজ, সোফা আকাশি/সরিষা, কার্পেট গোলাপি/ল্যাভেন্ডার, ল্যাম্প, দেয়ালঘড়ি (সেকেন্ডের কাঁটা ঘোরে), ফ্রেমে ছবি।
- ঘর (রাত): দেয়াল হালকা ল্যাভেন্ডার `#E6E0F4`, জানালায় নীল রাত-আকাশ + চাঁদ + বৃষ্টি (`rain`), ল্যাম্পের উষ্ণ আলো কাঁপে।
- আবেগের পটভূমি (`Night`): হালকা পেস্টেল রং + নরম রেডিয়াল আলো + ভাসমান রঙিন কণা (`#EEE6F8`, `#F6E8F0`, `#E4EEFB`, `#FBF1E6`…)।
- ছাদ (`Rooftop`): গ্রেডিয়েন্ট সন্ধ্যা-আকাশ, মিটমিটে তারা, চাঁদ, শহরের আলো জ্বলা ভবন, রঙিন বাতির মালা, ছাদের দেয়াল, টবের গাছ; `Bench`।
- শেষ/উষ্ণ মুহূর্ত: `GoldRays` (সোনালি রশ্মি)। CTA: `Sunburst` বা `GoldRays`।
- রাগ: `Tint color="#E04A30"` (পালস) + ক্যামেরা ঝাঁকুনি। স্মৃতি/ফ্ল্যাশব্যাক: পুরো দৃশ্যে `filter: sepia(0.55)` + ভিনিয়েট। একাকীত্ব: চরিত্রের ওপর স্পটলাইট, বাকিটা অন্ধকার, অন্য চরিত্র `dim`।

## ৩. চরিত্র-ডিজাইন
সব চরিত্র: ফ্ল্যাট ফিল + ৪–৫px গাঢ় আউটলাইন `#2A2420`, গোল মাথা, বড় সাদা চোখে কালো মণি, ছোট কান, সরল নাক/মুখ, নলের মতো হাত, ডিম্বাকৃতি জুতো। **ফর্সা ত্বক।** অঙ্গ আলাদা রিগ নয় — **ভঙ্গি = আগে থেকে আঁকা ভেরিয়েন্ট** (`pose`), মুখের ভাব (`face`)।
- ভঙ্গি: `stand, point, hips, scratch, open, crossed, chin, headHold, shrug, give, carry, phone, wipe, reach, hug`।
- মুখ: `neutral, surprised, annoyed, smile, happy, wink, sad, think, smug`।
- জীবন্ত রাখা (স্বয়ংক্রিয়, `Char`): চোখের পলক (~৩.৩s), শ্বাস-দোল, হালকা দোলা, কথা বললে মুখ নড়া + মাথা দোলা। `walkFrom`/`walk` দিয়ে হেঁটে আসা, `sit` বসা (হাঁটু/কোল দেখা যায়), `tilt` হেলান, `dim` ছায়ায় ফেলা, `flip` মুখ বাঁয়ে।
- **দম্পতি (`husband`/`wife`, `CouplePerson.tsx`)** — ব্যবহারকারীর পুনরাবৃত্ত চরিত্র; নাম স্ক্রিপ্ট থেকে নাও।
  - স্বামী: ~২৬ বছরের কিউট তরুণ মুখ, **খুব হালকা ছোট খোঁচা দাড়ি** (শুধু আভা), পাতলা গোঁফ, গালে হালকা লালচে, উঁচু করে আঁচড়ানো ঘন কালো চুল; ব্লেজার + সাদা শার্ট (রং বদলানো যায়: নেভি `#1F3358` / টিল `#2E6B7E`)।
  - স্ত্রী: সিঁথি করা খোলা লম্বা কালো সোজা চুল, গালে ছোট তিল, **নাকফুল নেই**; লম্বা কামিজে জরির কাজ (কালো `#1B1A1F` / মেরুন `#8A2846`), গলায় লাল পাথরের লকেট।
- **অন্য গল্পে নতুন চরিত্র** (`Person.tsx`-এর `LOOKS`): outfit `shirt|tee|panjabi|saree`, hair `neat|messy|grey|bun|kid|kidSpiky`, `beard {color, opacity}` (১ = ভরাট পাকা দাড়ি, ০.৪৫ = খোঁচা), `tie`, `glasses`, `shortSleeve`। উদাহরণ: অফিসার ছোট ভাই (সাদা শার্ট+নেভি টাই, পরিপাটি চুল), বড় ভাই (মলিন মরচে শার্ট, এলোমেলো খাড়া চুল, খোঁচা দাড়ি), বাবা (সাদা পাঞ্জাবি, পাকা চুল-দাড়ি, চশমা), মা (সবুজ শাড়ি, খোঁপায় পাকা রেখা), ছোটবেলার সংস্করণ (`kid*`, স্কেল ০.৮–০.৯৫)।
- আলাদা চরিত্রকে আলাদা চেনা যায় এমন পোশাক-রং ও চুল দাও।

## ৪. মোশন ("advanced animation")
- **ক্যামেরা** (`Cam keys=[[frame, scale, ox%, oy%], …]`): বক্তার দিকে প্যান/জুম, আবেগের লাইনে মুখে পুশ-ইন (১.৫–১.৯), দৃশ্য শেষে পুল-আউট; সবসময় ধীর ড্রিফট। রাগে `shake`।
- **ট্রানজিশন** (দৃশ্য ১০ ফ্রেম ওভারল্যাপ): `fade` (শান্ত), `slide`/`slideR` (দৃষ্টিভঙ্গি বদল), `zoom` (জোর), `whip` (ঝগড়ার কাটাকাটি, ব্লারসহ), `iris` (নতুন অধ্যায়/লোকেশন)। মিশিয়ে ব্যবহার করো।
- **ঢোকা:** চরিত্র/প্রপ স্প্রিং `PopIn` (delay = সেই শব্দের ফ্রেম)। সব ভিজুয়াল **ভয়েসের নির্দিষ্ট শব্দে** (`w(seg,'শব্দ')`)।
- **কিছুই স্থির নয়:** পটভূমির ঘড়ি, বৃষ্টি, তারা, বাতির মালা, কণা নড়ে।

## ৫. শব্দ
- ভয়েস + `bed.wav` (মিউজিক −২২dB, দৃশ্য বদলে হালকা whoosh, মূল মুহূর্তে চাইম)। মুড-সেকশন গল্পের আবেগের সাথে: ঝগড়া `tense` (হার্টবিট), দুঃখ/ভাবনা `sad` (ধীর পিয়ানো), মিটমাট `warm`, শিক্ষা/CTA `hope`।

## ৬. দৃশ্য-ভাষা (বাক্য → ছবি) — আগে কাজ করেছে
| বাক্যের ভাব | ভিজুয়াল |
|---|---|
| বাইরে হাসি, ভেতরে কষ্ট | হাসিমুখের মুখোশ (`SmileMask`) পাশে; তারপর মুখ বিষণ্ণ + মাথার ওপর বৃষ্টির মেঘ (`RainCloud`) |
| মন খারাপ/অভিমান | মাথার ওপর মেঘ থেকে বৃষ্টি; মুখ ফিরিয়ে `crossed` |
| না-বলা কথা / জমে থাকা কথা | হিজিবিজি কথার বাবল (`ScribbleBubble`) জমতে থাকে; দুজনের মাঝে লাল ড্যাশ লাইন + ✕ |
| ঝগড়ার শুরু / দূরত্ব | দুজনের মাঝে লাল ফাটল-রেখা আঁকা হয় + দুজন সরে যায়; ভাঙা হৃদয় (`HeartBroken split`) |
| ফোনে ব্যস্ত | হাতে জ্বলা ফোন (`pose="phone"`) + লাল পালস-রিং (`Ring`) + ক্যামেরা ফোনে জুম |
| সময় চাই | দেয়ালঘড়িতে রিং / `Clock` পপ |
| কাজ/পরিশ্রম | ব্রিফকেস (`Briefcase`), ঘাম (`Sweat`); কাজ বাদ = ব্রিফকেসে ✕ |
| ভবিষ্যৎ/সঞ্চয় | বাড়ি (`House`) + ভরে ওঠা জার (`Jar`) |
| রোজ কাজ, একদিন মন খারাপ | সপ্তাহের ক্যালেন্ডার (`WeekStrip`), এক দিনে মেঘ জ্বলে ওঠে |
| টাকা খরচ / নষ্ট | টাকার নোট (`Note`) উড়ে যায় / ঘুরে মিলিয়ে যায় |
| পড়া শেষ হয়নি | গ্র্যাজুয়েশন টুপিতে ✕ |
| অভাব / ত্যাগ | পয়সায় ✕, উপহারে ✕ |
| রাত জেগে পড়া | টেবিল (`Desk`), বইয়ের স্তূপ বাড়ে, দ্রুত ঘোরা ঘড়ি, চাঁদ, চোখের জল (`Tear`) |
| সাফল্য / নিজের চেষ্টায় ওঠা | অফিস ভবন (`Office`) + "বড় অফিসার!" স্ট্যাম্প; সোনালি ধাপের সিঁড়ি বেয়ে ওঠা |
| সাফল্য বনাম চাপা কষ্ট | পর্দা দুই ভাগ: সোনালি আলো বনাম ছায়া+মেঘ |
| তোমারও অংশ | "সাফল্য" চাকতি থেকে "ভাইয়া" টুকরো আলাদা হয়ে জ্বলে |
| তুলনা/শিক্ষা | দাঁড়িপাল্লা (`Balance`) সঠিক দিকে ঝুঁকে পড়ে |
| হাত ধরে রাখা | দুটো হাত এসে মিলে যায় (`HoldingHands`) |
| বইয়ের উক্তি | বই খোলে (`OpenBook`), উক্তি টাইপ হয় (`typed`); প্রতীক (মন্দিরের দুই স্তম্ভ `Temple`) |
| জড়িয়ে ধরা | দুজন কাছে এসে `pose="hug"`, সোনালি রশ্মি, হৃদয় |
| নতুন সকাল/পরিবর্তন | রাত থেকে ভোর (রং-ফেড), ঝিলিক, স্ট্যাম্প |
| মিটমাট/ভালোবাসা | মাঝখান থেকে হৃদয় ভেসে ওঠে, ঝিলিক; ছাদে পাশাপাশি বসা, কাঁধে হেলান (`tilt`) |
| প্রতিশ্রুতি/শর্ত | তালিকা-কার্ড (`ListRow`) + ✓ |
| CTA | লাইক/কমেন্ট/ফলো বোতাম (`SocialBtn`) ঠিক সেই শব্দে জ্বলে; নিচে চরিত্ররা ছোট করে, হাসিমুখে |
| স্মৃতি/ছোটবেলা | সেপিয়া ফিল্টার + ছোট সংস্করণের চরিত্র |
